## Methods

One-line fix: `CoreMLExecutionProvider::default().with_model_format(MLProgram)`
— the crash string "unable to compute the prediction using a neural
network model" names the legacy format; the ort crate documents
NeuralNetwork as its default while modern onnxruntime Python builds
partition this model fine (5 CoreML partitions, 55/64 nodes). Verified by
running the self-play generator end to end, then the full test suite,
tactical suite and critical corpus.

## Interpretation

CoreML restored at better-than-historical throughput (MLProgram ≈3×
faster per thread-second than the old path's ≈150 thread-s/game at
600/150). D-011's conditional — "128/32 conditional on restoring the
CoreML EP" — is now satisfied on the infrastructure side; at 128/32 the
self-play cost is small against plan ch. 16's envelope, leaving headroom
for multi-seed runs in both budget readings.
