## Raw results + uncertainty

**First run: 29 PASS, 0 FAIL, 1 SETUP-ERROR (C022).**

Disagreement C022 — investigated against the rules text, **corpus at
fault, engine correct**: the draw-case choreography moved the black queen
(2,0)→(1,1) in one slide with both cells flanking the step empty. The
origin touched only bB1 and the destination only wQ, so the hive would be
"left unlinked while the piece is in transit" — exactly the illegal-move
example of the One Hive rule (rulesheet p. 9). The engine's rejection is
the rule-mandated behaviour. Resolution: setup rerouted via (1,0), every
step keeping one occupied flanking cell; expectation (Draw on simultaneous
surround) unchanged. Correction documented in the case file.

**Second run (after setup fix): 30 PASS, 0 FAIL, 0 SETUP-ERROR.**
