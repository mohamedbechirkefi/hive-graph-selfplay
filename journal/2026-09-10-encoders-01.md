## Methods

Grid (tasks 1–3): reuse decision D-021; the frame-bounds `debug_assert`
became an always-on assert (release-silent-corruption hazard closed);
extremal tests added (28-piece straight lines per axis: full fit, full

`docs/representations/graph.md` (D-022 path: cell-graph, fixed

`python/hivenet/{graph_dataset,graph_model}.py`; property battery
`python -m hivenet.graph_checks` (P1 no information loss vs the record,
P2 capacities + loud overflow, P3 edge symmetry with reverse = (d+3) mod

zero illegal probability through a real forward pass). Costs (task 7):
matched-condition benchmarks both arms, same machine.

## Raw results + uncertainty

- Grid: hive-nn suite 7/7 incl. new extremal tests; plane crosscheck
  PASS (240 positions) after the assert hardening — the behaviour pin
  held.
- Graph checks over 300 real records: ALL OK. Max nodes 67/224, max
  legal 124/321; overflow probe raises loudly. One builder fix during
  bring-up: the empty-board position (ply 0) has an empty candidate set
  — mirrored `Frame::new`'s canonical-first-cell special case.
- Capacity: grid 1.44 M vs graph 1.47 M (+2.1%).
- Inference b1: best-provider grid 2.62 ms (CoreML) vs graph 3.67 ms
  (ORT CPU; CoreML is *worse* for the graph net — 9.84 ms, 147/287 nodes
  supported across 15 partitions). torch-CPU parity (11.0 vs 10.5 ms).
- Training b128: CPU fwd 138 vs 478 pos/s (graph 3.5× faster); MPS
  fwd+bwd 274 vs 138 pos/s (graph 2× slower — gather cost).
- Static-shape ONNX export of the graph net: clean, runs under
  onnxruntime — D-022's CoreML-compatibility premise holds structurally,
  though the *fast* provider for this net is CPU (reported, not hidden).

## Failures

None besides the journaled empty-board builder fix.

## Limits / confounders

Benchmarks are single-machine and single-configuration; the graph
dataloader's Python build cost is not yet in the training-throughput
numbers (generation dominates regardless); MPS numbers used a plain
fwd+bwd without optimizer step.

## Interpretation

Both representations now exist behind the identical decoder with
capacity matched to +2.1% and every cost difference measured and
reported (plan ch. 6's validation line: what changes between methods is
exactly enumerable — representation, network body, and their measured
hardware interactions; nothing else). The ≈1.4× best-provider inference
gap against the graph arm is precisely the kind of honest wall-clock
cost the dual budget readings exist for. Symmetry augmentation is
excluded from the full method (D-023), so the arms' data protocols are
trivially identical.
