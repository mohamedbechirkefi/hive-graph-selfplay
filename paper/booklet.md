# Booklet v1 assembly map (2026-10-09)

The booklet is assembled from these sources, in order. Each part is a
dated draft in this directory; the claims register (`claims.md`)
governs every claim in all of them.

| Booklet chapter | Source file(s) |
| --- | --- |

| 2 Formalisation | `ch2-formalisation.md` |
| 3 Related work | `ch3-related-work.md` |
| 4 Method | `method-validation.md` + `method-baselines.md` + `method-pipeline.md` + `method-representations.md` |
| 5 Protocol | `ch5-protocol.md` |
| 6 Results | `results-comparison.md` (incl. H-T3) |
| 7 Discussion & threats | `ch7-discussion.md` |
| 8 Working methodology (gated human–AI) | `ch-methodology.md` |
| 9 Conclusion | `ch8-conclusion.md` |
| Bibliography + Webographie | `bibliography.md` (generated) |
| Annex A — Position corpora (materialised) | `annex-corpus.md` (generated by `scripts/make_annex_corpus.py` from the executable TOML cases) |
| Annex B — Architectures, decoder, formats | `annex-architectures.md` |
| Annex C — Hyperparameters, seeds, commands | `annex-reproduction.md` |
| Annex D — Repository pointers | injected by `scripts/assemble_booklet.py` (configs/manifests, full conventions, claims register, journal) |
| Annex E — Result tables and figures (generated) | injected by `scripts/assemble_booklet.py` verbatim from `results/` and `figures/` |
| Figures | `figures/fig1–fig7` (all regenerate from `scripts/make_figures.py`) |
